# Patent Non-Assertion Pledge

## y.AI.y Ethical Anchor Project

The contributors to the y.AI.y ethical anchor project ("Project") make this Patent Non-Assertion Pledge to promote the development and adoption of ethical AI awareness models.

### Pledge

We, the contributors to this Project, pledge not to assert any patents we may have or acquire that cover the following against any person or entity implementing, using, or distributing implementations of the specifications and code in this Project:

1. The ethical awareness model architecture described in this repository
2. The local-first, secure ingot signing methodology
3. The canonical JSON byte representation system
4. The log10-suppressed event simulation framework
5. The policy engine for ethical rule enforcement

### Scope

This pledge applies to:
- Direct implementations of the Project's specifications
- Derivative works that maintain the ethical principles outlined in ethics/ethics_spec.json
- Non-commercial and commercial use

### Exceptions

This pledge does **not** apply if:
1. The implementer first asserts patent claims against contributors to this Project
2. The implementation is used for purposes that violate the ethical principles in ethics/ethics_spec.json

### Definitions

- "Assert" means to bring any claim, action, or suit for patent infringement
- "Contributors" means anyone who has contributed code, documentation, or specifications to this Project

### Effective Date

This pledge is effective as of the date of contribution and continues indefinitely.

This pledge is provided "as is" without warranty of any kind, express or implied.
